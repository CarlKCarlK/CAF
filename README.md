# Computers and Academic Freedom Archive

This is a preservation copy of the Computers and Academic Freedom (CAF) archive, originally hosted by EFF at `http://www.eff.org/CAF/` and also associated with `ftp://ftp.eff.org/pub/CAF/`.

It was reconstructed from a 2003 Internet Archive / Wayback Machine snapshot and lightly repaired for local and GitHub browsing, including icon/link fixes and directory index files. See `PROVENANCE.md` for details.

Generated per-directory and per-issue research indexes are preserved under `_research/`. They are useful for searching and summarizing the archive, but they are not original CAF archive documents. The larger combined research index is not included in this repository.
