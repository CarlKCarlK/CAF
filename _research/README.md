# Research Indexes

This directory contains generated research metadata for the preserved CAF archive. These files are not original CAF archive documents.

- `indexes/caf-archive-files/` preserves generated `doc_index1.json` and `*.batch_index1.json` files alongside their original archive-relative paths.
- The larger combined research index is not included in this repository.

Temporary restart files such as `*.tmp.jsonl` are intentionally excluded.
