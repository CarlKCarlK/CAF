# Provenance

This repository is a preservation copy of the Computers and Academic Freedom (CAF) archive as it appeared under EFF's old site, principally:

- `http://www.eff.org/CAF/`
- `ftp://ftp.eff.org/pub/CAF/`

The files were reconstructed from the Internet Archive / Wayback Machine, centered on the 3 Oct. 2003 snapshot:

- `https://web.archive.org/web/20031003002621/http://www.eff.org/CAF/`

Some local repairs were made to make the archive browsable again:

- root-relative image/icon links were rewritten or bridged for local and GitHub browsing
- missing shared EFF icon assets were restored where available
- generated directory index files were kept or rebuilt where needed
- duplicate first-pass Wayback download trees were excluded from this repository copy
- generated per-directory and per-issue research indexes are preserved under `_research/` and are not original CAF archive documents
- the larger combined research index is not included in this repository
- temporary indexing/restart files and local editor workspace files are not part of the repository copy

The source recovery workspace was a local working copy and is not part of this repository.

This repository is intended for preservation and readability. It is not a byte-for-byte copy of EFF's server.
