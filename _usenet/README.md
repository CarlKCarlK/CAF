# Usenet Source Material

This directory contains recovered Usenet/news source material from Carl Kadie's
personal email and news archive. These files are related to the history of the
Computers and Academic Freedom project, but they were not part of the original
CAF archive.

The files are included here as historical context and citation targets for
research and writing. They may include public discussion, quoted material,
offensive language, obsolete technical details, incomplete threads, duplicate
messages, or generated index sidecars.

Current contents:

- `misc.legal` - recovered Usenet/news archive file from `home/News/misc.legal`.
- `misc.legal.email_index3.json` - generated JSON index sidecar from the local
  research archive.
- `misc.legal.email_index2.tsv` - generated tab-separated index sidecar from the
  local research archive.
